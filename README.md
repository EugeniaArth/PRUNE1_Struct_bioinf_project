##  The six questions

| # | Question | Status |
|---|----------|--------|
| 1 | **Variant type** — HGVS, class (splice / missense / nonsense / …) | ✅ |

| 3 | **Localisation in the protein?** — domain, active site, interface, surface/core | ✅ |

| Parameter | Value |

> The 50-nt rule: any premature stop codon occurring before c.883 targets the transcript for nonsense-mediated decay. Stops at or after c.884 (including the native stop) escape NMD.

## Phase 4 — Cellular consequence (completed 2026-11-23)

Data extracted from `data/consequence_PRUNE1.json` (generated by `cellular_consequence.py`).

### Molecular consequence per transcript

| Transcript | NMD verdict | Protein made? | Mechanism |
|---|---|---|---|
| Δexon5 (in-frame, 159 nt) | NMD does not apply | Yes — 400 aa truncated | hypomorph or dominant-negative |
| Δexons4+5 (out-of-frame, 344 nt) | NMD-competent | No — degraded | haploinsufficiency contributor |

### gnomAD constraint

| Metric | Value | Interpretation |
|---|---|---|
| pLI | 0.011 | **Not LOF-constrained** — heterozygotes tolerate haploinsufficiency |
| LOF z-score | 2.42 | Moderate depletion of LOF variants |
| Observed LOF / Expected | 6 / 15.67 | Fewer LOF variants than expected |

> pLI = 0.011 confirms that PRUNE1 is **not haploinsufficient** — consistent with autosomal recessive inheritance where carriers have no phenotype.

### Summary

The c.521-2A>G allele produces two transcripts with opposite fates:
- **Δexon5** (in-frame): truncated PRUNE1 protein (400 aa, missing the inter-domain linker + DHHA2 edge) → **hypomorph**
- **Δexons4+5** (frameshift): degraded by NMD → **null**

Since PRUNE1-related syndrome is **autosomal recessive**, a homozygous patient has **two copies of this allele**. The net effect is **partial loss of function** — the truncated protein may retain residual activity, which the paper suggests produces a **primarily degenerative** (rather than purely developmental) phenotype.

*Source: gnomAD v2.1 exac_constraint via GraphQL API, accessed 2026-11-23*

##  Scripts in `scripts/`

All scripts are generic and reproducible via CLI arguments:

| Script | Purpose | Usage example |
|--------|---------|---------------|
| `classify_variant.py` | Variant classification + NMD analysis (Phase 1+2) | `--gene PRUNE1 --variant c.521-2A>G` |
| `protein_localisation.py` | Map residues to domains via InterPro (Phase 3) | `--gene PRUNE1 --uniprot Q86TP1 --variant c.521-2A>G --classify-json ...` |
| `variant_report.py` | Full variant report with exon figure + pLDDT panel | `--gene PRUNE1 --uniprot Q86TP1 --variant c.316G>A p.Asp106Asn --hpo HP:0010864` |
| `structure_analysis.py` | Protein structure geometry (Ramachandran, SASA, B-factor) | `--pdb 1DPX` or `--uniprot Q86TP1` |
| `multimer_analysis.py` | AlphaFold multimer interface metrics | `fold_dir --chain-a A --chain-b B --label-a PRUNE1 --label-b GSK3B` |
| `sbtools.py` | Structural biology toolkit (dependency) | (imported by other scripts) |

**Dependencies:** `sbtools.py` must sit next to scripts; `data/rama_allowed.npz` is needed by `structure_analysis.py`.
